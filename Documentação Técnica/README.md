# Documentação Técnica

Esta pasta armazena os documentos textuais e a fundamentação teórica que estruturam o projeto acadêmico do Mini Rack / Data Center.

**Responsável:** Ana Carolina Lisboa

### O que você encontra aqui

- **Síntese Teórica ([`SINTETIZAÇAO.docx`](SINTETIZAÇAO.docx)):** documento principal que consolida a base conceitual do trabalho. Ele abrange:
  - **Introdução e contextualização:** a evolução dos computadores e o desafio do gerenciamento térmico em hardware.
  - **Fenômenos de Transporte:** o equacionamento das resistências térmicas da cadeia (`Rjc`, `Rcs`, `Rsa`), condução 2D e o uso de simulações.
  - **Ciência dos Materiais:** a comparação atômica entre o Alumínio 6063-T5 e o Cobre C11000 com base no modelo de elétrons livres.
  - **Sustentabilidade e Meio Ambiente:** métricas de eficiência energética (PUE) e o descarte correto de resíduos eletrônicos (*e-waste*) conforme a ABNT NBR 16156.
